# 信用凭据跨机关迁移后的浏览器调档

档案调阅在 `/archive` 操作。选择查询机关并输入合成企业短码，显示索引任务号和当前结果。档页输入格式为 `档号/页号`，成组申请以逗号分隔。开放可单独领取的页面及份数在委托数据内，领取和再查流水均使用门户页面。同名任务号按机关区分。查询批分状态“检索仍在出页”“索引已封”，取档流水为“已受理”“文件可取”“明确未受理”。已受理一次扣一份。
 
档卷用 HTML 页表示电子扫描件，有 `签发号、机关、档号、册页、签发时间、声明适用时间`。新机关接手档页引用原档号和旧机关。扫描页上“联章待核”仅代表当页还缺册次签章信息。原页与重打件用短语标签清楚区分。`data/mandates.json` 给出批准可查看的档页、机关生效区间、份数与范围更新。演练中的有效期和签发时点是整数。

## 本地来源

资料均为合成记录。Node.js 22 环境下执行 `npm ci`，再用 `npm run sources` 启动，默认监听 `127.0.0.1:4180`。可用环境变量 `PORT` 修改端口。在容器中运行时，服务和访问端处于同一网络命名空间。

`data/sources.json` 保存原始报文及站点页面。连续响应由来源按同一进程内的观察次数提供。阶段从 `initial` 启动，本地演练人员可用 `POST /scenario/阶段名` 切换，未覆盖的路由延用初始响应。切换不清空来源的请求记录。重开服务会复位。

执行 `npm test` 核对来源契约。本机浏览器依赖由 Playwright 1.56.1 提供，可在首次准备时执行 `npx playwright install chromium`。容器方式可先执行 `docker build -t archive-filing-sources .`，再执行 `docker run --rm archive-filing-sources`。镜像准备完成后的验证不需要外网。

## 扫描的联章页

书面授权中的 `officeQuotas` 与 `quota` 分别是各机关和全委托的确认受理上限。以原机关的原册第 3 页为例，扫描清单中可能含同档号但不同企业的册页，不可使用该企业的联章号补其它企业档案。实际页头标有企业短码，扫描包外层不能替代该标识。

原机关最初的第一份领件可到达 W5。晚到的第二个受理号 W6 可能在首次打开索引时尚未显示，确认后的册页仍可按联章号共用。与新机关同号的 W5 分属各自受理记录。

## 收件系统（`intake/`）

跨机关档案收件在 `intake/` 内按领域驱动分层，不代办申报或信用修复，也不凭任何回执宣布信用等级。

- `domain/`：纯业务规则，无外部依赖。
  - `mandate.js` 授权批单与修订（撤回为批单级停效；多修订按有效区间并集授权，收窄修订不抹掉基础批单对其他机关的覆盖）；撤回后未交接页不得领取或出具，已交接页只留凭据、停止原件下载。
  - `index-task.js` 索引分片（“检索仍在出页/索引已封”），索引结果只作线索，同事项号按企业归属过滤。
  - `pull-request.js` 取档状态机与在途拦截：门户确认受理即扣份，窗口关闭不回退；同档在门户仍可能回件时禁止再耗一份，终态后给出可重领时点。
  - `quota-ledger.js` 机关独立结算份数与全委托总限额：提交预占、受理扣定、未受理释放、窗口关闭后迟到受理补扣或记透支冲突并冻结后续预占；不同企业台账互不影响。
  - `scan-package.js` 扫描核验：页头归属为权威标识，混入别家企业的页扣留不发窗口；联章待核给柜台查补页码，同企业已验明联章可在两笔已许可档卷间共用，跨企业联章号不认；唯一联章依据被扣留时转档案员核实。
  - `lineage.js` 签发/重打/更正/交接沿革：重打必须带旧档出处与承接范围才能接上原档；原件有效性与是否仍代表当前声明是两个独立判断；查旧见当时材料，查当前呈现已确认后件或注明缺页。
  - `handover.js` 交接凭证：载明所属期与签发机关、保留迁出证据，文案禁止信用等级结论。
  - `audit-log.js` 索引流水与取档流水分开编号、各自可复核。
- `infrastructure/`：`html-parser.js` 容错解析门户 HTML；`portal-client.js` 以浏览器表单方式查询、提交、轮询异步流水与取档，422 表单拒绝不产生受理、不扣份，“页面连接已关闭”转流水确认而非判失败。
- `application/intake-service.js`：固定编排 授权 → 在途拦截 → 份数预占 → 门户提交 → 异步受理对账 → 取档核验 → 企业交接。
- `demo.mjs` 可运行的全链路演示：`npm run demo`（自行拉起演练来源，跑完即关）。

领域单测与端到端测试在 `test/intake-*.test.mjs`，覆盖授权撤回、份数透支、同档禁重领、扫描归属与联章、迁移沿革、交接凭据及多企业隔离。
